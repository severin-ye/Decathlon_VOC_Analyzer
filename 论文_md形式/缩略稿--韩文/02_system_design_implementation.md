## II. 방법

본 논문은 상품 VOC 분석을 증거 기반 방법 절차로 구성한다. 핵심 목표는 리뷰 요약을 직접 생성하는 것이 아니라, 리뷰 속 주관적 피드백을 검색 가능하고 검증 가능하며 귀속 가능한 이미지-텍스트 증거 체인으로 변환하고, 통일된 구조 아래에서 질문 계획, 증거 검색, 실험 설명, 그림 제시를 수행하는 것이다.

### 전체 구조

Decathlon VOC Analyzer는 상품 VOC 분석을 증거 기반 다단계 프로세스로 형식화한다. 시스템은 먼저 상품 페이지의 텍스트, 이미지, 리뷰를 통일된 증거 공간으로 조직한다. 이후 리뷰 측면에서 측면 수준 사용자 피드백을 추출한다. 다음으로 질문 계획은 주관적 피드백을 실행 가능한 증거 질의로 변환한다. 마지막으로 상품 텍스트와 상품 이미지 사이에서 멀티모달 검색, 재순위, 증거 제약 생성을 수행한다 [1,2,3,7,8,9]. 단일 단계 대규모 모델 요약과 달리, 이 프레임워크는 "사용자가 무엇을 표현했는가", "상품 증거가 이를 지지할 수 있는가", "최종 보고서가 어떻게 귀속되는가"를 관찰 가능한 중간 단계로 분해한다.

시스템은 네 개의 논리 계층으로 구성된다. 상품 증거 계층은 상품 텍스트, 이미지, 국소 시각 영역의 구조화 표현을 구축한다. VOC 요구 계층은 리뷰를 측면, 의견, 감성, 사용 장면으로 변환한다. 증거 정렬 계층은 측면을 명확한 모달리티 경로를 가진 질문으로 다시 쓰고, 상품 증거 공간에서 후보를 검색하고 재순위화한다. 보고서 귀속 계층은 구조화 인사이트를 생성하고 보고서 claim을 리뷰 증거와 상품 증거에 매핑한다.

### 수식

리뷰 측면 $a$와 후보 증거 $e$의 순위를 통일하기 위해, 본 논문은 텍스트 관련성, 이미지 관련성, 교차 모달 일관성을 하나의 증거 점수로 결합한다.

$$
S(a, e) = \lambda_t R_t(a, e) + \lambda_v R_v(a, e) + \lambda_c C(a, e)
$$

여기서 $R_t(a, e)$는 텍스트 경로의 관련성 점수, $R_v(a, e)$는 이미지 경로의 관련성 점수, $C(a, e)$는 리뷰 측면과 상품 증거 사이의 교차 모달 일관성 제약을 의미한다. $\lambda_t$, $\lambda_v$, $\lambda_c$는 조정 가능한 가중치이다. 이 식은 최종 생성 분석을 대체하기 위한 것이 아니라, 검색과 재순위 단계에서 통일된 증거 선택 기준을 제공하기 위한 것이다.

### 실험 설명

상품 증거 표현 단계에서 시스템은 상품 제목, 설명, 카테고리, 규격, 이미지, 사용자 리뷰를 안정적인 식별자를 가진 증거 객체로 표현한다. 텍스트 증거는 출처 필드를 보존하고, 이미지 증거는 전체 이미지와 규칙 기반 국소 영역을 함께 보존하며, 리뷰 증거는 평점, 언어 힌트, 원문 조각을 보존한다. 이를 통해 이후 검색, 귀속, 평가를 위한 통일된 객체 경계를 마련한다.

리뷰 모델링 단계에서 시스템은 자연어 피드백을 측면 수준 VOC 단위로 변환한다 [10]. 각 측면 단위는 평가 대상 속성, 감성 경향, 의견 설명, 원문 증거 조각, 사용 장면, 신뢰도를 포함한다. 측면 수준 표현은 통계 집계뿐 아니라 특정 속성을 중심으로 한 증거 질의 생성도 지원한다. 제한된 리뷰 예산이 높은 별점의 짧은 리뷰에 점유되는 것을 피하기 위해, 시스템은 리뷰 추출 전에 별점 인지 샘플링을 도입하고 구조화 LLM 경로와 휴리스틱 경로를 모두 지원하여 모델 능력과 프로세스 완전성을 구분한다.

질문 계획 단계에서 시스템은 원시 리뷰를 직접 사용해 상품 증거를 검색하지 않는다. 대신 각 측면을 명확한 증거 의도를 가진 질문으로 변환한다. 이러한 질문은 텍스트 지지, 시각 확인, 교차 모달 설명이라는 세 가지 요구를 포괄한다. 텍스트 지지 질문은 상품 문구나 규격이 리뷰 의견을 지지하는지 확인하고, 시각 확인 질문은 상품 이미지가 관련 구조나 외관을 보여 주는지 확인하며, 교차 모달 설명 질문은 특정 피드백이 실제 제품 문제, 페이지 제시 부족, 사용자 기대 차이 중 어디에 가까운지 판단한다.

검색과 생성 단계에서 시스템은 두 단계 검색을 사용한다 [11,12]. 첫 단계는 벡터 표현을 사용해 상품 텍스트와 상품 이미지에서 후보 증거를 거칠게 회수하고, 두 번째 단계는 재순위 모델을 사용해 후보 집합을 정밀하게 정렬한다. 텍스트 경로는 주로 상품명, 카테고리, 설명, 규격, 명시적 약속을 검증하는 데 사용되고, 이미지 경로는 주로 구조, 외관, 색상, 국소 세부 사항을 검증하는 데 사용된다. 최종 보고서는 측면 집계를 기반으로 장점, 단점, 쟁점, 적합한 사용 장면, 증거 공백, 개선 제안을 생성하고, claim 수준 귀속을 통해 claim과 리뷰, 상품 텍스트, 상품 이미지 사이의 지지 관계를 표시한다.

시스템 구현은 구조화 객체로 다단계 프로세스를 제약한다 [4,5,6]. 모델 호출은 호환형 언어 모델 게이트웨이를 통해 수행되며, 검색 계층은 로컬 인덱스와 벡터 데이터베이스 두 종류의 백엔드를 지원한다. 공식 실험과 개발 검증을 구분하기 위해 시스템은 실행 정책 제어를 제공한다. 전체 모델 체인이 사용 가능할 때는 실제 벡터 인코더, 이미지 인코더, 재순위 모델을 사용하고, 외부 능력이 사용 불가능하며 정책이 허용할 때는 휴리스틱 경로로 후퇴하여 프로세스가 실행 가능하도록 한다. 이 설계는 모델 능력 부족과 프로세스 설계 실패를 혼동하지 않도록 한다.

본 논문의 현재 검증 목표는 고정된 대규모 benchmark의 최종 성능을 보고하는 것이 아니라, 시스템이 증거 기반 VOC 분석을 안정적으로 완료할 수 있는지를 확인하는 것이다. 결과는 현재 구현이 상품 증거 표준화, 리뷰 측면 모델링, 질문 계획, 멀티모달 후보 검색, 후보 재순위, 측면 집계, 보고서 생성, 증거 귀속을 순차적으로 완료할 수 있음을 보여 준다. 하나의 완전한 분석은 최종 자연어 보고서뿐 아니라 리뷰 측면, 질문 의도, 검색 질문, 회수된 증거, 검색 품질, 실행 설정, 측면 집계, 과정 추적, 보고서 귀속 등의 객체를 포함하므로, 사람이 검토하고 오류를 위치시키는 데 도움을 준다.

질문 수준 관련 증거 주석이 있을 때 시스템은 Recall@1, Recall@3, Recall@5, MRR, NDCG@3, NDCG@5 [13]를 계산할 수 있다. 구조화 보고서에 대해서는 claim이 리뷰, 상품 텍스트, 상품 이미지에 의해 지지되는지 통계화하며, 여기에는 claim support rate, claim grounded rate, citation precision, citation contradiction rate, 서로 다른 모달리티 경로의 기여 비율이 포함된다. 현재 구현은 166개의 자동화 테스트를 포함하고 모두 통과했으며, 이는 주요 인터페이스, 구조화 중간 표현, 워크플로 단언이 현재 구현에서 일관성을 유지함을 보여 준다.
