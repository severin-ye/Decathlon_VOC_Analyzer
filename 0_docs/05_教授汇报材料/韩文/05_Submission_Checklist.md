## Baseline 방법에 대한 설명

**현재 baseline 구현 방식**: 코드에 구현된 Lewis 2020, JARVIS, VeriCite는 논문 설명에 따라 본 시스템 내에서 적응한 단순화된 버전입니다. 동일한 LLM 게이트웨이와 검색 백엔드를 사용하여 공정한 비교가 가능하도록 했습니다. 이것은 외부 시스템의 실제 실행 결과가 아니라 대조군 baseline의 낮부 구현입니다.

**교수님 관점**: 교수님이 요구하는 "기능 테스트 비교"의 핵심은 **설계상의 차이와 기대 효과를 보여주는 것**입니다. 현재 데이터로 충분히 증명 가능합니다:
1. 완전한 시스템 > 소거 조건 (모듈별 필요성 검증)
2. 완전한 시스템 > 대조군 baseline (전체 아키텍처 우위 검증)
3. 각 소거 조건의 성능 저하 방향이 설계 예상과 일치
