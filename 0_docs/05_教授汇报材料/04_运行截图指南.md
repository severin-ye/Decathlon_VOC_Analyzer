### 截图 2：程序执行过程 / 프로그램 실행 과정

**截图内容**：终端运行完整流水线的日志输出

**操作命令**：

### 截图 3：输出目录结构 / 출력 디렉토리 구조

**截图内容**：运行后 `02_outputs/` 的目录树

**操作命令**：
```bash
tree 02_outputs/ -L 2
# 或
ls -R 02_outputs/ | head -40
```

**预期画面**：展示 `1_normalized/`, `2_aspects/`, `3_indexes/`, `4_reports/`, `5_feedback/`, `5_replay/`, `6_html/`, `7_manifests/` 的层级结构。

> **참고**: 이미 `02_outputs/`에 backpack_060, backpack_071, shoes_001 등의 기존 실행 결과가 있습니다. 스크린샷에 이 파일들이 보이면 "システムが過去に実行され、成果物が保持されていること"을 증명할 수 있습니다.

### 截图 4：HTML 报告页面（浏览器） / HTML 보고서 페이지

**截图内容**：浏览器中打开生成的 HTML 报告

**操作命令**：
```bash
# 已有现成报告，直接用浏览器打开
xdg-open 02_outputs/6_html/backpack/backpack_010.html 2>/dev/null || \
  firefox 02_outputs/6_html/backpack/backpack_010.html
```

**预期画面**：报告页面包含 strengths、weaknesses、evidence attribution 等内容。

> **참고**: backpack_010.html이 이미 존재합니다. 별도 실행 없이 바로 열 수 있습니다. 만약 없으면 `run_workflow.py` を --export-html 付きで実行してください.

---

### 截图 5：API 服务 Swagger 页面 / API 서비스 Swagger 페이지

**截图内容**：FastAPI 自动生成的 Swagger UI

**操作命令**：
```bash
# 终端1：启动 API 服务
uvicorn decathlon_voc_analyzer.app.api.main:app --reload

# 浏览器访问
# http://localhost:8000/docs
```

**预期画面**：7 个 API 端点列表，包括 `/health`, `/api/v1/dataset/overview`, `/api/v1/analysis/product` 等。

### 截图 6：分析报告 JSON 内容 / 분석 보고서 JSON 내용

**截图内容**：编辑器/终端中展示分析报告 JSON 的部分内容

**操作命令**：
```bash
# 已有现成的分析结果
python3 -m json.tool 02_outputs/4_reports/backpack/backpack_010_analysis.json | head -80

```

**预期画面**：JSON 中展示 strengths, weaknesses, controversies, evidence_gaps, suggestions, claim_attributions 等结构化字段。
