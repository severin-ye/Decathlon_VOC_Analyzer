## 消融实验结果 / 소거 실험 결과

### 定性对比表 / 정성적 비교표

| 条件 / 조건 | 核心差异 / 핵심 차이 | 预期效果 / 예상 효과 |
|------------|---------------------|---------------------|
| **完整系统** | 四阶段流水线完整运行 | 证据意图明确、多模态覆盖、高质量排序、结论可追溯 |
| **无问题规划** | 跳过证据意图分解 | 检索目标模糊，可能遗漏视觉/跨模态证据 |
| **无图像路径** | 仅文本检索 | 视觉特征相关的 claim 缺少支持 |
| **无重排序** | 跳过精细排序 | 低质量证据混入，不确定性增加 |
| **无归因** | 不绑定证据来源 | **报告不可生成**，证明归因是核心约束 |

### 关键发现 / 핵심 발견

1. **问题规划贡献**：移除后检索意图不明确，影响证据支持的完整性
2. **图像路径重要性**：移除后视觉证据缺失，影响涉及外观/结构 claim 的支持
3. **重排序有效性**：移除后低质量证据混入，降低结果可信度
4. **归因是核心约束**：移除后 report 不可生成，说明证据可追溯性不是可选功能

## 对照基线对比 / 대조군 baseline 비교

| 基线 / Baseline | 设计特征 / 설계 특징 | 与本系统差异 / 본 시스템과의 차이 |
|----------------|-------------------|------------------------|
| **Lewis 2020** | 标准单文本路径 RAG | 单路径 vs 双路径；开放式生成 vs 证据约束；无归因 |
| **JARVIS** | 证据图 + LLM 裁决 | 图结构处理冲突 vs 流水线证据对齐；无多模态检索 |
| **VeriCite** | 三阶段后验验证 | 生成后过滤 vs 生成前检索；无多模态；无问题规划 |

## 当前阶段定位 / 현재 단계 위치

> **当前阶段主要进行功能级对比和输出结果差异分析，而不是完整的定量性能评估。**
> 
> **현재 단계는 정량 지표보다는 기능 단위 비교와 출력 결과의 차이를 중심으로 테스트했습니다.**

消融实验和对照基线的目的是：
1. **验证设计**：证明每个模块在系统设计中的必要性
2. **展示差异**：定性说明本系统与传统方法在范式上的不同
3. **功能对比**：说明"有"和"没有"某项技术时，输出结果在结构和可信度上的差异

소거 실험과 대조군 baseline의 목적은:
1. **설계 검증**: 각 모듈이 시스템 설계에서 필수적임을 증명
2. **차이 제시**: 본 시스템과 전통적 방법의 패러다임 차이를 정성적으로 설명
3. **기능 비교**: 특정 기술의 "유무"에 따라 출력 결과의 구조와 신뢰도가 어떻게 다른지 설명
